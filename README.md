# TPWeb
1. Copiar el web URL del repositorio.
2. Desde una terminal abrir la carpeta en la cuál vas a clonar el repositorio (cd nombreCarpeta).
3. Una vez dentro de la carpeta, desde la misma terminal ejecuta los siguientes comandos:
   1. git clone <url del repositorio> // clona el repositorio en tu carpeta
   2. cd TPWeb // ingresa a la carpeta del proyecto
   3. git fetch --all // trae todas las ramas del repositorio
   4. git switch tp1 // cambia a la rama donde esta el código ejecutable
4. Ejecutar el servidor con el siguiente comando: go run main.go
5. Se mostrará el siguiente mensaje: Servidor iniciado en http://localhost:8080/
6. Haz click en el link y disfrutá nuestra página!
